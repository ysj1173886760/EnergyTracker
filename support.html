饮食、运动、体重与趋势记录。支持 iOS 17 及以上的 iPhone。

如何开始

在「今天」页面添加饮食或体重。选择「直接填热量」可以在不使用 AI 的情况下记录。在「我的」中填写个人资料与目标。

如何开启 AI

AI 功能面向年满 18 岁且符合 OpenRouter 使用条件的用户。先在「隐私与 AI 数据」阅读说明并授权，再在「模型与 API Key」填写自己的 OpenRouter API Key。先点「验证 Key」检查凭证，再点「测试当前模型」验证实际推理能否运行；模型测试只使用固定测试文字和生成的纯色图片，不会发送个人记录。AI 调用（包括模型测试）可能产生第三方服务费用。若提示无可用端点，需要选择支持零数据保留的模型。请先检查 OpenRouter 的内容日志与安全留存设置；零数据保留路由仍有服务政策规定的例外。请勿在支持邮件中发送 API Key。

如何备份和换机

本机快照不会同步到云端，卸载 App 会丢失。换机前主动导出 JSON 备份到自己的电脑；新设备通过「从备份文件恢复」合并导入。备份含个人健康信息，请勿公开分享。
